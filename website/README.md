# Veeniksha Public Website

Public-facing website for Veeniksha Veena & Music Classes.

## Current sections
- Home / hero
- About Veeniksha
- Know Your Guru
- Learning experience
- Student stories
- Embedded Google Form registration
- Phone and WhatsApp inquiry links

## Registration
The public Google Form is embedded directly in `index.html`. Responses remain managed by Google Forms and can be linked to Google Sheets.

## Local preview
Open `index.html` in a browser or serve the `website` directory with any static HTTP server.

## Deployment
This folder is static HTML/CSS/JavaScript and can be deployed using GitHub Pages, Cloudflare Pages, Netlify, or Vercel. A future full-stack version can integrate with the existing Veeniksha Academy Flask application.
